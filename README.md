# NEO-SYNTAX — Abdullah's Portfolio

A cinematic GitHub-powered portfolio built as a fully static site (HTML/CSS/JS) and hosted free on GitHub Pages.

**Live:** https://riorioriorio000000-debug.github.io/neo-syntax-portfolio/

## Features
- Live GitHub data (repos, stats, activity) fetched client-side
- NEO-SYNTAX design system (Obsidian Black / Electric Cyan / Matrix Green)
- IBM Plex Mono + Inter typography
- Full SEO (meta, Open Graph, robots.txt, sitemap.xml)
- Terminal-style interactive contact section

## Tech
Static HTML/CSS/JS — no build step, no backend.
